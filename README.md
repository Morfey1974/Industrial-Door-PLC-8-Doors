# PLC 8 DOORS

Прошивка для **STM32H723** и **Web UI (React/Vite)**: одна плата, до **8 дверей**, зависимости и параметры задаются через браузер по Ethernet (стендовый сценарий, короткий кабель).

## Состав репозитория

| Папка | Назначение |
|--------|------------|
| `Core/` | HAL, FreeRTOS, `main`, инициализация периферии по CubeMX |
| `App/` | Логика: двери, конфиг QSPI, HTTP API, журнал, пользователи (данные в Flash) |
| `BSP/` | GPIO дверей, замков, индикации |
| `LWIP/` | Стек и `ethernetif` |
| `WebUI/` | Интерфейс оператора |

## Сборка прошивки

1. Открыть проект в **STM32CubeIDE** (файл `.cproject` в корне).
2. Убедиться, что в **Debug/App/system/subdir.mk** участвуют нужные `App/system/*.c` (при добавлении новых модулей вне CubeMX — вручную или через настройки проекта).
3. Собрать конфигурацию **Debug**.

## Сборка Web UI

Первый раз — зависимости только в **`WebUI/`**:

```bash
cd WebUI
npm install
```

Дальше можно из **корня репозитория** (удобно из PowerShell в папке проекта):

```bash
npm run dev
```

Или, как раньше, только из `WebUI`: `cd WebUI` → `npm run dev`.

Сборка статики: `npm run build:web` из корня или `npm run build` из `WebUI`.

Статика для встраивания в прошивку формируется скриптами проекта (см. `WebUI/README.md`).

## CubeMX: что отключить и что проверить

Цель — чтобы при **Generate Code** не появлялись лишние задачи и периферия под старый «мультиплат» проект.

1. **Connectivity → FDCAN**: отключить (нет CAN в этой ветке проекта).
2. **Connectivity → UART4**: отключить, если использовался только RS‑485.
3. **I2C** (в т.ч. PB6/PB7 под DS3231): отключить — **внешней RTC в прошивке нет**, время в журнале опирается на заголовок **X-Client-Time** из браузера или на tick.
4. **FreeRTOS → Tasks and Queues**: не должно быть задач **canTask** и **rs485Task** (в актуальном `freertos.c` их нет; в `.ioc` список задач приведён к этому виду).
5. После генерации проверить **USER CODE** в `Core/Src/freertos.c`: не должно остаться `osThreadNew(StartCanTask…)` / `StartRs485Task`.

Папки **`App/`** и **`BSP/`** при перегенерации CubeMX обычно **не перезаписываются** — их содержимое и пути include в IDE нужно сохранять вручную.

## HTTP и безопасность

Для стенда в `http_api.c` по умолчанию включён режим **`HTTP_OPEN_ACCESS`** (запросы к `/api/...` без проверки Bearer-токена). Для сетевой установки с паролями задайте в препроцессоре проекта **`HTTP_OPEN_ACCESS=0`** и используйте обычный вход через API пользователей.
