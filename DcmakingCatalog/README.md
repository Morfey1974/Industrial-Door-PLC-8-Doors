# DCM Catalog — многоязычный каталог (EN / RU / HE)

Локальная копия контента сайта dcmaking.co.il в виде статического каталога: товары с фото, описанием и ценой, форма запроса по товару (без корзины и оплаты), страницы «О нас» и «Контакты». Три языка: английский (по умолчанию), русский, иврит (RTL).

---

## Структура проекта

```
DcmakingCatalog/
├── index.html          # Выбор языка (EN / RU / HE)
├── en/                 # Английская версия
│   ├── index.html      # Главная
│   ├── products.html   # Каталог товаров
│   ├── product.html   # Страница товара (содержимое по #id в URL)
│   ├── about.html      # О нас
│   └── contact.html    # Контакты
├── ru/                 # Русская версия (те же страницы)
├── he/                 # Иврит (RTL)
├── css/
│   └── site.css
├── js/
│   ├── products-data.js  # Данные товаров и подписи UI на EN/RU/HE
│   └── site.js           # Навигация, страница товара по hash, форма запроса
├── img/                # Фото товаров (см. ниже)
└── README.md
```

## Фото товаров

Контент с dcmaking.co.il перенесён в HTML и в `js/products-data.js`. **Изображения нужно скопировать вручную** с живого сайта в папку `img/`:

1. Откройте https://www.dcmaking.co.il/products и страницы товаров.
2. Сохраните изображения каждого товара в папку `DcmakingCatalog/img/` под именами:
   - `door-controller.jpg`
   - `electric-bolt.jpg`
   - `the-membrane-traffic-light-narrow.jpg`
   - `the-traffic-light-narrow.jpg`
   - `the-traffic-light-membrane-wide.jpg`
   - `expansion-board-for-sliding-doors.jpg`
   - `expansion-board-for-electromagnet.jpg`
3. (По желанию) Добавьте `img/placeholder.jpg` — он будет подставляться, если у товара нет файла.

Пока изображений нет, браузер покажет «сломанную» картинку; после добавления файлов всё отобразится.

## Просмотр локально и редактирование в Visual Studio

### Вариант 1: Локальный веб-сервер (рекомендуется)

При открытии файлов по протоколу `file://` часть сценариев (например, загрузка данных) может вести себя иначе. Лучше запустить простой сервер в папке `DcmakingCatalog`:

- **VS Code / Cursor:** расширение «Live Server» — правый клик по `index.html` → «Open with Live Server».
- **Из командной строки** (из папки `DcmakingCatalog`):
  - Python 3: `python -m http.server 8080`
  - Node (npx): `npx serve . -p 8080`

После этого откройте в браузере: `http://localhost:8080/` — отобразится выбор языка, затем можно переходить по EN / RU / HE и страницам.

### Вариант 2: Открыть папку в Visual Studio

1. В Visual Studio: **File → Open → Folder** и выберите папку **DcmakingCatalog** (или корень решения, в котором она лежит).
2. Редактируйте HTML, CSS, JS как обычные файлы.
3. Для просмотра используйте локальный сервер (см. выше) или разверните сайт на хостинге и смотрите по домену.

## Выкладка на хостинг

Когда будут известны домен и хостинг, ниже можно заполнить конкретные шаги. Общая схема:

### Что нужно от вас

- Тип хостинга: **только статика** (HTML/CSS/JS + папка `img/`) или хостинг с панелью (cPanel, Plesk и т.п.).
- Домен (например, `dcmaking.co.il`) и куда он привязан (DNS, панель хостера).
- Способ загрузки: **FTP/SFTP**, **веб-панель (файловый менеджер)**, **Git** или **drag-and-drop** (например, Netlify/Vercel).

### Общая инструкция (статика)

1. **Подготовка**
   - Убедитесь, что в папке `img/` лежат все нужные фото (и при необходимости `placeholder.jpg`).
   - Проверьте сайт локально через `http://localhost:8080/` (или другой порт).

2. **Загрузка файлов**
   - Загрузите на хостинг **всё содержимое** папки `DcmakingCatalog` в **корень сайта** (обычно `public_html`, `www`, `htdocs` или папка, указанная в настройках домена):
     - файл `index.html` в корень;
     - папки `en/`, `ru/`, `he/`, `css/`, `js/`, `img/` — целиком, с сохранением структуры.
   - После загрузки адреса должны быть такими:
     - `https://ваш-домен/` — выбор языка;
     - `https://ваш-домен/en/` — главная (английский);
     - `https://ваш-домен/ru/`, `https://ваш-домен/he/` — русский и иврит.

3. **Домен и HTTPS**
   - В панели хостинга привяжите домен к этой папке (если ещё не привязан).
   - Включите SSL (Let’s Encrypt или сертификат от хостера), чтобы сайт открывался по `https://`.

4. **Проверка**
   - Откройте `https://ваш-домен/` → выберите язык → проверьте главную, каталог, страницу товара, «О нас», «Контакты».
   - Проверьте форму запроса по товару (открытие формы и переход в почту или отправка на сервер, если позже подключите бэкенд).

### Если хостинг конкретный (cPanel, Netlify, GitHub Pages и т.д.)

Напишите, каким хостингом пользуетесь (и по возможности панель или способ загрузки), и можно будет добавить сюда пошаговую инструкцию под ваш вариант (включая домен и при необходимости редирект с `www` на без `www` или наоборот).

## Форма запроса по товару

Сейчас форма на странице товара открывает почтовый клиент (`mailto:info@dcmaking.co.il`) с темой и телом письма. Чтобы запросы приходили на сервер или в CRM, нужно будет:

- заменить `action` формы на URL вашего бэкенда или сервиса (например, Formspree, Getform),  
- либо добавить простой серверный скрипт (PHP/Node и т.д.), который принимает POST и отправляет письмо.

Домен и хостинг вы укажете позже — тогда можно будет описать конкретные шаги и при необходимости обновить этот README.
