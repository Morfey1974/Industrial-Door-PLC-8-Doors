# Industrial Door PLC - Web Interface

Web-интерфейс для управления промышленным контроллером дверей.

## Технологии

- **React 18+** - UI библиотека
- **Vite** - Сборщик и dev-сервер
- **React Router** - Маршрутизация
- **Axios** - HTTP клиент

## Быстрый старт

### Предварительные требования

- Node.js 18+ и npm
- Visual Studio 2022 или Visual Studio Code

**Подробная инструкция по установке и интеграции в Visual Studio:** см. файл `INSTALL_VS.md`

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Приложение откроется на `http://localhost:3000` (или на IP этого ПК в LAN — см. `host: true` в Vite).

**Связь с контроллером:** запросы в dev идут на **тот же хост, что и UI** (`/api/...`), а **Vite проксирует** их на платы по адресу из `.env.development` → `VITE_DEV_PROXY_TARGET` (по умолчанию `http://192.168.1.50`). Так браузер не делает cross-origin на МК и не упирается в CORS. Смените IP/порт в `.env.development`, если у платы другие настройки.

Обход прокси для отладки: откройте UI с параметром  
`?controller=http://ДРУГОЙ_IP` — тогда снова прямой запрос (нужен разрешённый Origin на МК или `*`).

Старый URL в `localStorage` (`plc_controller_url`) в **режиме dev не используется** (только после `npm run build` / продакшн-статика), чтобы не тянуть адрес с другого ПК.

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## Интеграция с Visual Studio

**ВАЖНО:** Подробная пошаговая инструкция находится в файле `INSTALL_VS.md`

Краткая версия:
1. Установите Node.js (если не установлен)
2. Откройте папку `WebUI` в Visual Studio через "Файл → Открыть → Папка"
3. В терминале выполните `npm install`
4. Запустите `npm run dev`

## Реализованные функции

### ✅ Завершено
- **Главная страница (Dashboard)** — обзор состояния системы и дверей
- **Мониторинг → Двери** — полная таблица состояния всех дверей с фильтрацией по статусу и ID
- **Мониторинг → События** — журнал событий с фильтрацией (тип, ID двери, источник) и пагинацией
- Автообновление данных каждые 10 секунд
- Обработка ошибок и таймаутов
- Оптимизированная загрузка данных (только активная страница)

### 🚧 В разработке
- Мониторинг → Алармы
- Мониторинг → Статистика
- Конфигурация → Настройка дверей
- Настройки → Параметры системы (сеть, общие параметры контроллера)
- Настройки → Профиль пользователя

## API Endpoints

Базовый URL контроллера настраивается в `src/utils/constants.js`

- `GET /api/state` - Состояние системы
- `GET /api/doors` - Состояние дверей
- `GET /api/config` - Конфигурация
- `PUT /api/config` - Обновление конфигурации
- `GET /api/journal/stat` - Статистика журнала
- `GET /api/journal/dump?offset=0&limit=20` - Записи журнала (максимум 50 записей за запрос)

## Цветовая схема

- **Primary:** `#3A6577` (Темно-бирюзовый)
- **Secondary:** `#EDEDED` (Светло-серый)
- **Accent:** `#E6332A` (Красный)

Все цвета определены в `src/styles/variables.css`
