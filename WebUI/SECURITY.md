# Безопасность промышленного контроллера дверей

## Цели

- **Защита от взлома:** недопущение несанкционированного доступа третьих лиц.
- **Промышленная безопасность:** корректная работа логики дверей, предотвращение некорректной конфигурации.
- **Удалённое администрирование:** безопасный доступ администратора для настройки, диагностики и устранения неисправностей.

---

## Реализованные меры

### 1. Аутентификация и роли

- **Пользователи:** логин и пароль (минимум 8 символов).
- **Роли:** Super Admin, Admin, Operator — с разными правами доступа.
- **Права:** настраиваются через «Настройки → Права доступа».
- **Смена пароля:** доступна всем пользователям в «Профиль».
- **Восстановление пароля:** токен генерирует только Super Admin.

### 2. Контроль доступа

- API проверяет права для каждой операции.
- **Полный удалённый доступ** (раздел «Параметры системы») — **только Супер-администратор**. Admin и Operator не имеют доступа.
- Конфигурация дверей — только Admin и Super Admin.
- Управление пользователями — только Super Admin.
- Оператор — просмотр мониторинга и смена своего пароля.

### 3. Журнал событий

- События открытия/закрытия дверей, алармы, системные события записываются в QSPI Flash.
- Используется для аудита и диагностики.

---

## Рекомендации для безопасного удалённого доступа

### Обязательно

1. **VPN:** при доступе через интернет или между подсетями используйте VPN предприятия. Контроллер не должен быть доступен напрямую из интернета без VPN.

2. **Сильные пароли:** минимум 8 символов, рекомендуется сочетание букв, цифр и спецсимволов. Регулярная смена паролей администраторов.

3. **Минимальные права:** выдавайте пользователям минимально необходимый уровень доступа (Operator, Admin, Super Admin).

### Желательно

4. **Firewall:** на маршрутизаторе ограничьте доступ к контроллеру только с доверенных IP или VPN.

5. **HTTPS:** при появлении поддержки в прошивке — включайте HTTPS для шифрования трафика.

6. **Локальная сеть:** предпочтительно подключаться из той же подсети, что и контроллер.

---

## Ограничения текущей версии

- **HTTP:** соединение без шифрования. Для удалённого доступа через интернет обязательно используйте VPN.
- **CORS:** `Access-Control-Allow-Origin: *` — для удобства отладки. В производственной среде рекомендуется ограничить домены.
- **HTTPS:** пока не поддерживается на контроллере.

---

## Промышленная безопасность (функциональная)

- Контроллер управляет физическими дверями. Несанкционированное изменение конфигурации может привести к некорректной работе логики дверей.
- Все изменения конфигурации требуют аутентификации Admin/Super Admin.
- Журнал событий фиксирует системные события для аудита.
