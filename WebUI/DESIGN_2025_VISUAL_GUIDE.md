# Визуальное руководство по дизайну 2025

## Цветовая палитра

### Основные цвета (сохранены)
```
Primary (Темно-бирюзовый):  #3A6577
  - Использование: Header, Sidebar, акценты
  - Градиент: #3A6577 → #2a4d5a
  - Glassmorphism: rgba(58, 101, 119, 0.15)

Accent (Красный):           #E6332A
  - Использование: Логотип, активные элементы, кнопки
  - Градиент: #E6332A → #c42a22
  - Glassmorphism: rgba(230, 51, 42, 0.15)

Secondary (Светло-серый):  #EDEDED
  - Использование: Фон, неактивные элементы
  - Градиент: #f5f7fa → #EDEDED
```

## Визуальные эффекты

### 1. Glassmorphism (Стеклянный эффект)

**Применение:**
- Header (верхняя панель)
- Login контейнер
- Карточки контента
- Модальные окна

**Код:**
```css
background: rgba(255, 255, 255, 0.1);
backdrop-filter: blur(20px) saturate(180%);
border: 1px solid rgba(255, 255, 255, 0.2);
```

### 2. Градиенты

**Primary градиент:**
```css
background: linear-gradient(135deg, #3A6577 0%, #2a4d5a 100%);
```

**Accent градиент:**
```css
background: linear-gradient(135deg, #E6332A 0%, #c42a22 100%);
```

**Градиентный текст (логотип):**
```css
background: linear-gradient(135deg, #E6332A 0%, #ff4d3d 100%);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
```

### 3. Тени и глубина

**Уровни теней:**
- XS: `0 1px 2px rgba(58, 101, 119, 0.05)`
- SM: `0 2px 4px rgba(58, 101, 119, 0.08)`
- MD: `0 4px 12px rgba(58, 101, 119, 0.12)`
- LG: `0 8px 24px rgba(58, 101, 119, 0.16)`
- XL: `0 16px 48px rgba(58, 101, 119, 0.2)`

**Glow эффект:**
```css
box-shadow: 0 0 20px rgba(230, 51, 42, 0.3);
```

### 4. Скругления

**Радиусы:**
- XS: 4px (маленькие элементы)
- SM: 6px (кнопки small)
- MD: 10px (стандартные элементы)
- LG: 16px (карточки, панели)
- XL: 24px (большие контейнеры)
- 2XL: 32px (модальные окна)
- Full: 9999px (badges, круглые элементы)

## Компоненты

### Header (Верхняя панель)

**Визуальные характеристики:**
- Полупрозрачный фон с blur
- Градиент от primary к более темному
- Sticky позиционирование
- Мягкая тень снизу
- Градиентный логотип DCM
- Hover эффект на логотипе (подъем + свечение)

**Анимации:**
- Плавное появление при загрузке
- Подъем при hover на логотипе
- Плавные переходы

### Sidebar (Боковая панель)

**Визуальные характеристики:**
- Градиентный фон (primary)
- Glassmorphism для пунктов меню
- Активный пункт с accent градиентом
- Индикатор активного пункта (полоска справа)
- Hover эффект (сдвиг вправо + подъем)

**Анимации:**
- Shine эффект при hover (световая полоса)
- Сдвиг вправо при hover
- Плавные переходы цветов

### Buttons (Кнопки)

**Primary кнопка:**
- Градиент accent цвета
- Тень с glow эффектом
- Ripple эффект при клике
- Подъем при hover

**Secondary кнопка:**
- Белый фон
- Граница при hover меняется на primary
- Плавные переходы

**Анимации:**
- Ripple волна при клике
- Подъем на 2-3px при hover
- Плавные переходы цветов

### Cards (Карточки)

**Визуальные характеристики:**
- Glassmorphism фон
- Мягкие тени
- Скругленные углы (16-24px)
- Градиентная полоска слева при hover (для door cards)

**Анимации:**
- Подъем при hover (translateY -4px)
- Увеличение тени при hover
- Плавные переходы

### Tables (Таблицы)

**Визуальные характеристики:**
- Градиентный header
- Чередующиеся строки с легкой прозрачностью
- Скругленные углы таблицы
- Hover эффект на строках

**Анимации:**
- Легкое увеличение строки при hover
- Плавные переходы цветов

### Status Badges (Бейджи статусов)

**Визуальные характеристики:**
- Градиентные фоны
- Полностью скругленные (pill shape)
- Мягкие тени
- Пульсация для алармов

**Анимации:**
- Пульсация для status-alarm
- Легкое увеличение при hover

## Анимации и переходы

### Стандартные переходы
- **Fast:** 150ms
- **Base:** 300ms (основной)
- **Slow:** 500ms

### Easing функции
- **Standard:** cubic-bezier(0.4, 0, 0.2, 1)
- **Bounce:** cubic-bezier(0.68, -0.55, 0.265, 1.55)

### Типы анимаций
- **Fade in:** появление элементов
- **Slide:** сдвиг элементов
- **Scale:** масштабирование
- **Lift:** подъем при hover
- **Ripple:** волна при клике
- **Pulse:** пульсация для важных элементов

## Состояния элементов

### Hover
- Подъем элемента (translateY -2px до -4px)
- Увеличение тени
- Изменение цвета/градиента
- Плавные переходы

### Active
- Легкое нажатие (translateY 0 или 1px)
- Уменьшение тени
- Ripple эффект (для кнопок)

### Focus
- Glow эффект вокруг элемента
- Увеличенная тень
- Цветная граница (accent)

### Disabled
- Пониженная непрозрачность (0.5-0.6)
- Отключенные анимации
- Серый цвет
