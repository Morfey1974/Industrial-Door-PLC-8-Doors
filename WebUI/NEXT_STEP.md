## Инструкция по выполнению

### 1. Установить зависимости (если еще не установлены)

```bash
cd "c:\Users\morfe\STM32CubeIDE\workspace_1.17.0\Industrial Door PLC\WebUI"
npm install
```

### 2. Запустить dev-сервер

```bash
npm run dev
```

### 3. Начать разработку

Откройте файлы в Visual Studio:
- `src/pages/Login.jsx` - для доработки страницы входа
- `src/context/AuthContext.jsx` - для реализации логики аутентификации
- `src/App.jsx` - для добавления PrivateRoute

### 4. Проверить результат

После реализации:
- Откройте `http://localhost:3000`
- Должна отображаться страница входа
- После "входа" должен происходить переход на Dashboard
