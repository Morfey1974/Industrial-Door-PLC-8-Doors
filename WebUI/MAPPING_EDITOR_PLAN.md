# Графический редактор карт помещений и дверей

## Обзор проекта

Создание страницы "Маппинг" в UI для визуального отображения и редактирования схем помещений с дверями. Редактор должен поддерживать два режима: редактирование карты и просмотр/мониторинг состояния дверей в реальном времени.

## Техническое решение: SVG + React

### Обоснование выбора SVG над Canvas

**Рекомендация: SVG (React)**

#### Преимущества SVG для данного проекта:

1. **Интерактивность и события**
   - Нативные DOM-события на каждом элементе (onClick, onMouseOver, onDrag)
   - Легко выделять, перемещать, редактировать отдельные объекты
   - Простая реализация drag-and-drop

2. **Масштабирование и производительность**
   - Векторная графика - масштабирование без потери качества
   - React управляет DOM, обновляются только измененные элементы
   - Эффективное обновление при изменении состояния дверей

3. **Интеграция с React**
   - Нативная поддержка JSX
   - Компонентный подход
   - Легкая связь с данными дверей через props/state

4. **Обновление состояния в реальном времени**
   - Обновление через React state/props
   - Меняется цвет индикатора двери - обновляется только этот элемент
   - Эффективно для режима мониторинга

5. **Сериализация и сохранение**
   - Структурированный DOM
   - Легко сохранять как XML/JSON
   - Простая валидация структуры

6. **Производительность**
   - Для 10-50 дверей и 20-100 стен производительность достаточна
   - React оптимизирует обновления через Virtual DOM

#### Когда Canvas был бы предпочтительнее:
- Тысячи объектов на экране
- Сложная анимация/градиенты
- Обработка изображений/пикселей
- Игры/тяжелая графика

**Вывод:** Для проекта с 10-50 дверьми SVG + React - оптимальное решение.

## Структура страницы "Маппинг"

### Верхняя панель
- **Название проекта** (из конфигурации)
- **Переключатель режимов:**
  - "Редактирование" - полный доступ к инструментам
  - "Просмотр" - только мониторинг состояния
- **Кнопки управления:**
  - Сохранить карту
  - Загрузить карту
  - Очистить карту
  - Экспорт (опционально)

### Центральная область рисования
- **SVG canvas** с белым фоном
- **Масштабирование:**
  - Колесико мыши (zoom in/out)
  - Ограничение зума (min: 0.1x, max: 5x)
  - Сохранение позиции при зуме
- **Панорамирование:**
  - Drag для перемещения карты
  - Стрелки клавиатуры (опционально)
- **Сетка** (обязательно, toggle on/off)
  - Размер ячейки: настраиваемый (по умолчанию 20px)
  - Визуальное выравнивание объектов
  - Привязка к сетке при включенной привязке
- **Координаты курсора** (опционально, для точного позиционирования)
- **Привязка (snap):**
  - Привязка по концам линий (для стен) - обязательно
  - Привязка к сетке (если включена) - обязательно
  - Привязка к центрам объектов (двери, метки) - обязательно
  - Привязка к пересечениям линий - обязательно
  - Радиус привязки: настраиваемый (по умолчанию 10-15px)
  - Визуальная индикация точки привязки

### Правая панель инструментов

#### Инструменты рисования:
1. **Выбор/Перемещение** (курсор)
   - Выделение объектов
   - Перетаскивание объектов
   - Изменение размера (handles)

2. **Рисование стены** (линия)
   - Клик для начала стены
   - Клик для конца стены
   - Толщина стены (настраиваемая)
   - **Привязка по концам линий (snap to endpoints):**
     - Автоматическая привязка к ближайшей конечной точке существующих линий/стен
     - Радиус привязки: 10-15 пикселей (настраиваемый)
     - Визуальная индикация привязки (подсветка точки привязки)
     - Привязка работает как при начале, так и при завершении рисования стены

3. **Вставка двери** (прямоугольник/иконка)
   - Выбор из списка доступных дверей системы
   - Привязка к `globalDoorId`
   - Стандартный размер двери

4. **Индикатор состояния двери** (светофор)
   - Автоматически привязан к двери
   - Зеленый: открыта/разблокирована
   - Красный: заблокирована/аларм
   - Обновление в реальном времени

5. **Вставка номера** (текст)
   - Номер двери/помещения
   - Настраиваемый размер шрифта

6. **Вставка комментария** (текст/метка)
   - Текстовая метка
   - Многострочный текст
   - Настраиваемый размер

7. **Удаление объектов**
   - Выделить объект → Delete
   - Или кнопка "Удалить" в панели инструментов

## Функциональность

### Режим редактирования

**Возможности:**
- Рисование всех типов объектов (стены, двери, метки)
- **Привязка объектов (snap):**
  - Привязка по концам линий при рисовании стен
  - Привязка к сетке (если включена)
  - Привязка к центрам объектов (двери, метки)
  - Привязка к пересечениям линий
  - Визуальная индикация активной привязки
- Редактирование объектов:
  - Перемещение (drag)
  - Изменение размера (resize handles)
  - Поворот (опционально)
- Удаление объектов
- Привязка дверей к реальным дверям из системы:
  - Выбор из dropdown списка
  - Отображение `globalDoorId`
  - Валидация привязки
- Сохранение карты в конфигурацию
- **Undo/Redo** (обязательно, для удобства редактирования)
  - История изменений (стек операций)
  - Горячие клавиши: Ctrl+Z / Ctrl+Shift+Z
  - Кнопки в панели инструментов

**Ограничения:**
- Только для ролей: Super Admin, Admin
- Валидация структуры перед сохранением

### Режим просмотра/мониторинга

**Возможности:**
- Только просмотр карты (без редактирования)
- Обновление состояния дверей в реальном времени:
  - Подписка на WebSocket или polling
  - Автоматическое обновление цветов индикаторов
- Интерактивность:
  - Клик по двери → информация о состоянии
  - Tooltip с деталями двери
- Масштабирование и панорамирование
- Доступно для всех ролей (Operator, Admin, Super Admin)

**Отображение состояния:**
- 🟢 Зеленый: дверь открыта/разблокирована
- 🔴 Красный: дверь заблокирована/аларм
- 🟡 Желтый: дверь открыта слишком долго (опционально)
- ⚪ Серый: дверь отключена/нет данных

**Анимация состояния дверей:**
- Плавная анимация при изменении состояния (открыта ↔ закрыта)
- Визуальная индикация открытия/закрытия двери на карте
- Переход цвета индикатора с анимацией (fade transition)
- Длительность анимации: 300-500ms

### API Endpoints

**GET /api/config/mapping**
- Загрузка карты из конфигурации
- Возвращает JSON карты
- Если карты нет - возвращает пустую структуру

**PUT /api/config/mapping**
- Сохранение карты в конфигурацию
- Валидация JSON структуры
- Проверка привязок дверей (существуют ли `globalDoorId`)
- Сохранение в QSPI через ConfigService
- Только для Super Admin и Admin

**Валидация:**
- Проверка формата JSON
- Проверка типов объектов
- Проверка координат (в разумных пределах)
- Проверка привязок дверей к существующим дверям

## Связь с реальными дверями

### При создании/редактировании двери на карте:

1. **Выбор двери:**
   - Dropdown список всех доступных дверей
   - Отображение: "Дверь {localDoor} (Плата {nodeId})"
   - Фильтрация по платам (опционально)

2. **Привязка:**
   - Сохранение `globalDoorId` в объекте двери
   - Валидация: дверь должна существовать в конфигурации
   - Отображение статуса привязки

3. **Визуализация:**
   - Иконка двери (стандартный вид)
   - Индикатор состояния (круг рядом с дверью)
   - Номер двери (текст)

### В режиме мониторинга:

1. **Подписка на обновления:**
   - Использовать существующий API `/api/doors`
   - Polling каждые 2-5 секунд
   - Или WebSocket (если будет реализован)

2. **Обновление индикаторов:**
   - Маппинг `globalDoorId` → объект индикатора на карте
   - Обновление цвета на основе состояния:
     - `locked === true` → красный
     - `locked === false && !alarming` → зеленый
     - `alarming === true` → красный (мигание опционально)

3. **Интерактивность:**
   - Клик по двери → модальное окно с деталями:
     - Номер двери
     - Плата
     - Состояние (заблокирована/разблокирована)
     - Время открытия
     - Алармы

## Технические детали привязки (Snap)

### Алгоритм привязки по концам линий

**При рисовании стены:**
1. При движении мыши вычислять расстояние до всех конечных точек существующих линий/стен
2. Если расстояние меньше `snapRadius` - активировать привязку
3. Визуально отображать точку привязки (маленький круг или крестик)
4. При клике - использовать координаты точки привязки вместо координат курсора

**Оптимизация:**
- Поиск только среди видимых объектов (viewport culling)
- Квадродерево или пространственная индексация для быстрого поиска
- Кэширование конечных точек при изменении объектов

**Визуальная индикация:**
- Подсветка точки привязки (круг или крестик)
- Линия от курсора до точки привязки (опционально)
- Изменение курсора при активной привязке

**Настройки:**
- Включение/выключение привязки (toggle)
- Радиус привязки: 5-30 пикселей (по умолчанию 15px)
- Типы привязки (все обязательны):
  - К концам линий (обязательно)
  - К сетке (если включена) (обязательно)
  - К центрам объектов (двери, метки) (обязательно)
  - К пересечениям линий (обязательно)

**Алгоритм привязки к центрам объектов:**
- При движении мыши вычислять расстояние до центров всех объектов (двери, метки, комментарии)
- Если расстояние меньше `snapRadius` - активировать привязку к центру
- Приоритет: пересечения > концы линий > центры объектов > сетка

**Алгоритм привязки к пересечениям линий:**
- Вычислять все точки пересечения существующих линий/стен
- При движении мыши проверять расстояние до ближайшего пересечения
- Если расстояние меньше `snapRadius` - активировать привязку
- Визуальная индикация точки пересечения

   - Визуальная индикация точки пересечения

## Заключение

Графический редактор карт помещений и дверей - реализуемая задача среднего уровня сложности. Использование SVG + React обеспечит:
- Простую интеграцию с существующим кодом
- Эффективное обновление состояния
- Хорошую производительность для типичных сценариев использования
- Легкую поддержку и расширение функциональности

Рекомендуется начать с базовой реализации (стены, двери, текст) и постепенно добавлять функциональность.
