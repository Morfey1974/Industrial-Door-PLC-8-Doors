## Как проверить:

1. **Обновите страницу в браузере** (F5)
2. **Откройте Dashboard** - перейдите на главную страницу или кликните на вкладку "Мониторинг" → "Двери" (Dashboard откроется по умолчанию)
3. **Проверьте подключение к контроллеру:**
   - Если контроллер доступен по `http://192.168.1.50`, данные должны загрузиться
   - Если контроллер недоступен, вы увидите ошибку подключения

## Настройка IP контроллера:

Если IP контроллера отличается от `192.168.1.50`, измените в файле `src/utils/constants.js`:

```javascript
export const API_BASE_URL = process.env.VITE_API_BASE_URL || 'http://ВАШ_IP';
```

Или создайте файл `.env` в корне проекта `WebUI/`:

```
VITE_API_BASE_URL=http://192.168.1.100
VITE_API_PORT=8080
```

## Что вы увидите:

- **Карточки состояния системы:**
  - Node ID
  - Роль (MASTER/SLAVE)
  - Статус сети (Готова/Не готова)
  - Link (UP/DOWN)
  - IP адрес
  - Время работы (формат: "2д 3ч 15м")

- **Таблица дверей:**
  - ID двери
  - Статус (с цветовым кодированием)
  - Замок (Заблокирована/Разблокирована)
  - Время открытия (если открыта)

- **Автообновление:** Данные обновляются каждые 10 секунд автоматически
