# Решение проблемы 404 на localhost:3000

## Проблема
При открытии `http://localhost:3000/` появляется ошибка 404.

## Решение

### Шаг 1: Проверьте расположение index.html

**Важно:** В Vite `index.html` должен быть в **корне проекта** (рядом с `package.json`), а НЕ в папке `public/`.

Структура должна быть:
```
WebUI/
├── index.html  ← ДОЛЖЕН БЫТЬ ЗДЕСЬ
├── package.json
├── vite.config.js
├── public/     ← Статические файлы (favicon, и т.д.)
└── src/
```

### Шаг 2: Установите зависимости

Откройте терминал в папке `WebUI` и выполните:

```bash
npm install
```

Это установит все необходимые пакеты (React, Vite, и т.д.).

### Шаг 3: Запустите dev-сервер

После установки зависимостей выполните:

```bash
npm run dev
```

Вы должны увидеть:
```
  VITE v5.0.8  ready in 500 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
```

### Шаг 4: Откройте в браузере

После запуска сервера откройте:
```
http://localhost:3000
```

## Если проблема сохраняется

### Проверка 1: Убедитесь, что сервер запущен

В терминале должно быть сообщение о том, что сервер запущен на порту 3000.

### Проверка 2: Проверьте порт

Если порт 3000 занят, Vite автоматически выберет другой порт (3001, 3002, и т.д.). 
Смотрите в терминале, какой порт используется.

### Проверка 3: Проверьте структуру файлов

Убедитесь, что файлы существуют:
- `index.html` в корне WebUI/
- `src/main.jsx`
- `src/App.jsx`

### Проверка 4: Очистите кэш

```bash
# Остановите сервер (Ctrl+C)
# Удалите папку node_modules и package-lock.json
rm -rf node_modules package-lock.json

# Переустановите зависимости
npm install

# Запустите снова
npm run dev
```

### Проверка 5: Проверьте консоль браузера

Откройте DevTools (F12) и проверьте вкладку Console на наличие ошибок.

## Типичные ошибки

### Ошибка: "Cannot find module 'react'"
**Решение:** Выполните `npm install`

### Ошибка: "Port 3000 is already in use"
**Решение:** 
1. Остановите другой процесс на порту 3000
2. Или измените порт в `vite.config.js`:
   ```javascript
   server: {
     port: 3001,  // Другой порт
   }
   ```

### Ошибка: "Failed to resolve import"
**Решение:** Проверьте, что все импорты в файлах правильные и файлы существуют.
