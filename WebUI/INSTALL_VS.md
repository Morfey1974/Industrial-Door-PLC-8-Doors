## Предварительные требования

### Что нужно установить:

1. **Node.js** (версия 18 или выше)
   - Скачать: https://nodejs.org/
   - Выбрать LTS версию (Long Term Support)
   - При установке убедиться, что опция "Add to PATH" включена

2. **Visual Studio 2022** (или Visual Studio Code)
   - Visual Studio 2022 Community (бесплатная): https://visualstudio.microsoft.com/
   - Или Visual Studio Code: https://code.visualstudio.com/

3. **Git** (опционально, если используете Git)
   - Обычно уже установлен, если используете Git

## Установка Node.js и npm

### Шаг 1: Проверка установки Node.js

1. Откройте **PowerShell** или **Command Prompt** (Win+R → `cmd`)
2. Выполните команду:
   ```bash
   node --version
   ```
3. Должна отобразиться версия, например: `v18.17.0` или выше
4. Проверьте npm:
   ```bash
   npm --version
   ```
5. Должна отобразиться версия, например: `9.6.7` или выше

### Шаг 2: Если Node.js не установлен

1. Перейдите на https://nodejs.org/
2. Скачайте **LTS версию** (рекомендуется)
3. Запустите установщик
4. Следуйте инструкциям установщика
5. **Важно:** Убедитесь, что опция "Add to PATH" включена
6. После установки перезапустите терминал
7. Проверьте установку снова (команды из Шага 1)

## Установка зависимостей проекта

### Шаг 1: Открыть терминал в папке проекта

**Вариант A: Через проводник Windows**
1. Откройте проводник Windows
2. Перейдите в папку проекта:
   ```
   c:\Users\morfe\STM32CubeIDE\workspace_1.17.0\Industrial Door PLC\WebUI
   ```
3. В адресной строке проводника введите `powershell` и нажмите Enter
   - Или нажмите Shift + ПКМ (правая кнопка мыши) в пустом месте папки
   - Выберите "Открыть окно PowerShell здесь"

**Вариант B: Через командную строку**
1. Откройте Command Prompt или PowerShell
2. Выполните команду:
   ```bash
   cd "c:\Users\morfe\STM32CubeIDE\workspace_1.17.0\Industrial Door PLC\WebUI"
   ```

### Шаг 2: Установить зависимости

В открытом терминале выполните:

```bash
npm install
```

**Что происходит:**
- npm читает файл `package.json`
- Скачивает все необходимые пакеты (React, Vite, и т.д.)
- Устанавливает их в папку `node_modules/`
- Это может занять 2-5 минут в зависимости от скорости интернета

**Ожидаемый результат:**
```
added 234 packages, and audited 235 packages in 45s
```

### Шаг 3: Проверка установки

Выполните команду для проверки:

```bash
npm list --depth=0
```

Должны отобразиться установленные пакеты:
- react
- react-dom
- react-router-dom
- axios
- vite
- и другие

## Настройка Visual Studio

### Вариант 1: Visual Studio 2022 (полная версия)

1. Откройте **Visual Studio Installer**

3. Убедитесь, что установлены следующие рабочие нагрузки:

## Запуск проекта

### Шаг 1: Открыть терминал в Visual Studio

**В Visual Studio 2022:**
1. **Вид → Терминал** (или `Ctrl+` ` - обратная кавычка)
2. Или **Инструменты → Командная строка → Разработчик**

**В Visual Studio Code:**
1. **Вид → Терминал** (или `` Ctrl+` ``)
2. Или используйте встроенный терминал внизу

### Шаг 2: Убедиться, что вы в правильной папке

В терминале выполните:

```bash

```

```bash
pwd
```

Должен отобразиться путь к папке `WebUI`.

### Шаг 3: Запустить dev-сервер

Выполните команду:

```bash
npm run dev
```

**Что происходит:**
- Vite запускает dev-сервер
- Компилирует React приложение
- Открывает браузер автоматически (если настроено)
- Приложение доступно на `http://localhost:3000`

**Ожидаемый результат:**
```

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

### Шаг 4: Открыть в браузере

1. Если браузер не открылся автоматически, откройте вручную:
   ```
   http://localhost:3000
   ```
2. Вы должны увидеть страницу с текстом "Industrial Door PLC - Web Interface"

В терминале нажмите `Ctrl+C` для остановки dev-сервера.

## Настройка для разработки

### Настройка Task Runner в Visual Studio 2022

1. **Вид → Другие окна → Диспетчер задач**
2. В диспетчере задач нажмите **Обновить привязки**
3. Должны появиться задачи из `package.json`:
   - `dev` - запуск dev-сервера
   - `build` - сборка для продакшена
   - `preview` - предпросмотр собранной версии
4. Двойной клик на задаче `dev` для запуска

### Настройка запуска в Visual Studio Code

#### Способ 1: Через терминал (рекомендуется)

Просто используйте встроенный терминал и команды `npm run dev`, `npm run build` и т.д.

#### Способ 2: Через задачи (Tasks)

1. Создайте файл `.vscode/tasks.json`:
   ```json
   {
     "version": "2.0.0",
     "tasks": [
       {
         "label": "dev",
         "type": "npm",
         "script": "dev",
         "problemMatcher": [],
         "isBackground": true,
         "presentation": {
           "reveal": "always",
           "panel": "new"
         }
       },
       {
         "label": "build",
         "type": "npm",
         "script": "build",
         "problemMatcher": []
       }
     ]
   }
   ```

2. Запуск: `Ctrl+Shift+P` → "Tasks: Run Task" → выберите задачу

### Настройка отладки (опционально)

#### Для Visual Studio Code:

1. Создайте файл `.vscode/launch.json`:
   ```json
   {
     "version": "0.2.0",
     "configurations": [
       {
         "name": "Launch Chrome",
         "type": "chrome",
         "request": "launch",
         "url": "http://localhost:3000",
         "webRoot": "${workspaceFolder}/src"
       }
     ]
   }
   ```

2. Установите расширение **Debugger for Chrome** (если нужно)

## Решение проблем

### Проблема 1: "npm не является внутренней или внешней командой"

**Решение:**
1. Node.js не установлен или не добавлен в PATH
2. Переустановите Node.js с опцией "Add to PATH"
3. Перезапустите терминал и Visual Studio

### Проблема 2: "npm ERR! code EACCES" или ошибки прав доступа

**Решение:**
1. Запустите терминал от имени администратора
2. Или используйте `npm install --global` с правами администратора

### Проблема 3: "Cannot find module 'vite'"

**Решение:**
1. Убедитесь, что вы в папке `WebUI`
2. Выполните `npm install` снова
3. Проверьте, что папка `node_modules` существует

### Проблема 4: Порт 3000 уже занят

**Решение:**
1. Измените порт в `vite.config.js`:
   ```javascript
   server: {
     port: 3001,  // или другой свободный порт
   }
   ```
2. Или остановите процесс, использующий порт 3000

### Проблема 5: Visual Studio не видит файлы .jsx

**Решение:**
1. Установите расширения для JavaScript/React
2. В Visual Studio Code установите расширение **ES7+ React/Redux/React-Native snippets**

### Проблема 6: Медленная работа npm install

**Решение:**
1. Используйте другой реестр npm:
   ```bash
   npm config set registry https://registry.npmjs.org/
   ```
2. Или используйте yarn:
   ```bash
   npm install -g yarn
   yarn install
   ```

### Проблема 7: Ошибки при сборке

**Решение:**
1. Удалите папку `node_modules` и файл `package-lock.json`
2. Выполните `npm install` заново
3. Проверьте версию Node.js (должна быть 18+)
