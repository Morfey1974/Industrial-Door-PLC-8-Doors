# Итог чата (январь 2025)

Краткое резюме для перехода в новый чат по теме **«Улучшения в Настройках»**.

---

## 1. Статус сети и шапка

- **StateDataContext** — глобальное состояние (сеть, Link, IP) для шапки на всех страницах.
- Статус сети, Link, IP и сообщение «Нет связи» + кнопка «Повторить» перенесены в **Header** (видны на всех страницах).
- **Dashboard** — убран блок статуса/ошибки, страница только по дверям.
- **Время работы (uptime)** убрано из блока статуса в шапке.

## 2. Надёжность статуса сети

- В **useApi** добавлена опция **`consecutiveFailuresForError: 3`** (для StateDataContext).
- Ошибка «Нет связи» показывается только после **трёх подряд** неудачных опросов состояния, чтобы при долгой загрузке страницы (например, События) статус не мигал.

## 3. Стили блока статуса в шапке

- Блок статуса приведён к блоку пользователя: тот же фон, рамка, **border-radius** (`var(--radius-lg)`), высота **44px**, **hover** (подсветка + `translateY(-1px)`).
- Размер зелёных кружков статуса увеличен (14px).

## 4. Подтверждение ухода из маппинга

- **LeaveConfirmContext** — при несохранённых изменениях в карте маппинга показывается модальное окно «В карте маппинга есть несохранённые изменения. Выйти без сохранения?» (Остаться / Выйти).
- Срабатывает при переходе: по сайдбару, по вкладкам, по клику на **логотип** (главная).
- **Mapping** регистрирует проверку `isDirty` для пути `/configuration/mapping`.
- В **App** навигация идёт через **tryNavigate** (сайдбар, вкладки); в **Header** логотип при клике вызывает **goHome()** → `tryNavigate('/')`.

## 5. Правила и команды Cursor

- **`.cursor/rules/repository-save.mdc`** — правила сохранения в репозитории:
  - «Сохрани в репозитории» = коммит **и** push.
  - Формат сообщения коммита, примеры, не использовать `--no-verify` без запроса.
- **`.cursor/commands/save-repo.md`** — быстрая команда **`/save-repo`** в чате: коммит + push по этим правилам.
- **`.cursor/rules/language.mdc`** — всегда русский в чате (ответы, рассуждения, комментарии в проекте).
