# Подключение модуля DS3231 RTC (синий модуль с AliExpress)

## Схема подключения

| Модуль DS3231 | Плата контроллера |
|---------------|-------------------|
| VCC           | +3.3 V             |
| GND           | GND                |
| SCL           | PB6 (I2C1_SCL)     |
| SDA           | PB7 (I2C1_SDA)     |

EEPROM на модуле нет — используем только DS3231 (часы реального времени).

---

## Настройка в STM32CubeIDE (CubeMX)

**Важно:** в CubeMX **не нужно** включать пункт **RTC** (встроенные часы STM32). Мы используем **внешний** модуль DS3231 по I2C — для него настраивается только **I2C1** (пины PB6/PB7).

---

## Настройка I2C1 в CubeMX

### 1. Открыть конфигурацию пинов

1. Откройте проект в **STM32CubeIDE**.
2. Дважды щёлкните по файлу **`Industrial Door PLC.ioc`** в Project Explorer (или правый клик → **Open With** → **STM32CubeMX**), чтобы открыть конфигуратор.

### 2. Включить I2C1 и назначить пины

1. В дереве **Pinout & Configuration** выберите **Connectivity** → **I2C1**.
2. В режиме **Mode** выберите **I2C** (не оставляйте Disabled).
3. Нажмите на пины **PB6** и **PB7** на графической схеме микроконтроллера:
   - **PB6** должен автоматически стать **I2C1_SCL**.
   - **PB7** — **I2C1_SDA**.
   - Если пины заняты другими функциями, сначала снимите с них назначение (правый клик → **Reset Signal**), затем снова выберите I2C1.

### 3. Параметры I2C1

1. В разделе **Configuration** (внизу) откройте **I2C1**.
2. **I2C Speed Mode**: оставьте **Standard Mode** (100 kHz) — для DS3231 этого достаточно.
3. **I2C Clock Speed**: 100000 Hz (или оставьте по умолчанию).
4. Остальные параметры (DMA, прерывания) можно не включать — драйвер использует опрос (polling).

### 4. Генерация кода

1. Меню **Project** → **Generate Code** (или кнопка с шестерёнкой).
2. Подтвердите перезапись файлов, если спросит (пользовательский код в блоках **USER CODE BEGIN/END** не трогайте).
3. После генерации в проекте появятся:
   - **Core/Src/i2c.c** — инициализация I2C1.
   - **Core/Inc/i2c.h** — объявление `hi2c1`.
   - В **main.c** в блоке инициализации периферии появится вызов **MX_I2C1_Init()**.

### 5. Сборка и прошивка

1. **Project** → **Build Project**.
2. Подключите модуль DS3231 к PB6, PB7, +3.3 V, GND.
3. Прошейте плату и откройте **терминал UART3** (скорость, как в настройках USART3, обычно 115200 8N1).

---

## Тест по UART (монитор)

- При включении питания на UART3 выводится строка вида:
  - `RTC: OK 2025-02-02 12:34:56` — время прочитано с DS3231.
  - `RTC: fail` — модуль не ответил (проверьте проводку и питание).
- Каждые 5 секунд задача **rtcTestTask** выводит текущие время и дату с RTC.
- **Проверка после отключения основного питания:** установите время (через код или один раз вручную), отключите питание платы на 10–30 секунд (модуль питается от батарейки на DS3231). Включите снова — на UART должно вывестись продолжение времени (секунды увеличились). Если батарейки нет, после включения время может сброситься или показывать старые значения до первого обновления.

---

## Файлы проекта, связанные с RTC

- **App/drivers/ds3231.c**, **App/drivers/ds3231.h** — драйвер чтения времени/даты с DS3231 по I2C.
- **App/system/rtc_test_task.c** — задача FreeRTOS: периодическое чтение RTC и вывод в UART3.
- **Core/Src/i2c.c**, **Core/Inc/i2c.h** — инициализация I2C1 (при регенерации CubeMX перезапишет эти файлы своей версией — поведение останется тем же).

---

## Регенерация кода CubeMX

Весь **наш** код (RTC, DS3231, тест по UART) лежит либо в блоках **USER CODE BEGIN/END** в `main.c` и `freertos.c`, либо в папке **App/** — CubeMX эти участки и файлы **не трогает**, при регенерации они **не теряются**.

Единственное, что CubeMX может **перезаписать** при «Generate Code» — это **Core/Src/i2c.c** и **Core/Inc/i2c.h**: конфигуратор подставит свою сгенерированную версию под настройки I2C1 из .ioc (PB6/PB7, 100 kHz). Функционально это то же самое, ничего не теряется.
