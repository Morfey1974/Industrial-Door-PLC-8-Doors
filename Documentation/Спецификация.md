Финальная спецификация NC-двери
Поведение
ALARM — импульс
Каждое нажатие ALARM запускает или продлевает окно разблокировки.
Приоритет MASTER
Разблокировка возможна только если LogicCore не требует блокировку (locked из LogicCore = 0).
Проверка: LogicCore_IsLockRequired(gid) == 0.
Окно разблокировки
Глобальный параметр ncUnlockWindowMs (по умолчанию 5000 мс).
При разрешённом импульсе дверь разблокируется на ncUnlockWindowMs.
Повторный импульс в течение окна — таймер сбрасывается.
Если дверь не открылась до истечения окна — замок снова блокируется.
Блокировка после закрытия NC
Глобальный параметр ncLockDelayAfterCloseMs (по умолчанию 1000 мс).
После физического закрытия — ждать ncLockDelayAfterCloseMs и заблокировать.
Это не postCloseTimeoutMs — отдельная переменная для NC.
Зависимости
Открытие NC: зависимости активны.
Закрытие NC: сразу EVT_DOOR_POST_CLOSE_READY (как для NC без post-close).
Зависимые двери возвращаются в свои состояния по логике.
Без сигнализации
Нет LED-мигания и buzzer при нажатии ALARM.
Параметры конфигурации (вкладка «Общие параметры»)
Поле	Ключ в JSON	Единица	По умолчанию
Окно разблокировки NC (с)	ncUnlockWindowSec / ncUnlockWindowMs	с / мс	5
Задержка блокировки NC после закрытия (с)	ncLockDelayAfterCloseSec / ncLockDelayAfterCloseMs	с / мс	1

3. Структура состояния NC в doors_task
Состояние per-door для NC:- ncUnlockWindowEndMs     — 0 или время окончания окна- ncLockAfterCloseStartMs — 0 или время начала задержки- ncLockAfterClosePending — 0/1Импульс ALARM (NC):  if LogicCore_IsLockRequired(gid) return;  ncUnlockWindowEndMs = now + ncUnlockWindowMs;Каждый цикл (NC):  if ncUnlockWindowEndMs && now > ncUnlockWindowEndMs && physClosed:    lock door, ncUnlockWindowEndMs = 0  if physClosed && !ncLockAfterClosePending:    ncLockAfterCloseStartMs = now, ncLockAfterClosePending = 1  if ncLockAfterClosePending && (now - ncLockAfterCloseStartMs >= ncLockDelayAfterCloseMs):    lock door, ncLockAfterClosePending = 0, ncLockAfterCloseStartMs = 0
4. Важные моменты
Зависимости
Для NC при закрытии нужно продолжать публиковать EVT_DOOR_POST_CLOSE_READY сразу (без post-close), чтобы LogicCore обрабатывал зависимости.
Циклические зависимости
logic_core.h не должен включать doors_task.h.
doors_task.c включает logic_core.h и вызывает LogicCore_IsLockRequired().
Это допустимо, если logic_core.h объявляет только эту функцию.
Совместимость конфига
При отсутствии полей в JSON использовать значения по умолчанию (5000 мс и 1000 мс).
Версия формата
При добавлении полей в project_config_t стоит обновить CFG_FORMAT_VERSION и предусмотреть миграцию старых конфигов.
